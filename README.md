# 🩺 Breast Cancer Prediction

[🚀 Live Demo](https://breast-cancer-prediction-ml-yv2ccmkar2q5e7p7patcyg.streamlit.app/)

A machine learning web application that predicts whether a breast
tumor sample is benign or malignant using a Support Vector Classifier.

## Features

- SVC machine learning model
- StandardScaler preprocessing
- Interactive Streamlit interface
- Patient-friendly input sections
- Dark-themed UI
- Example values for demonstration

## Machine Learning

Model: Support Vector Classifier (SVC)

Kernel: RBF

The model was trained using the Wisconsin Breast Cancer dataset.

## Performance

Accuracy: 98.25%

Confusion Matrix:

[[71, 0],
 [2, 41]]

## Tech Stack

- Python
- NumPy
- Pandas
- Scikit-learn
- Streamlit
- Joblib
